# Myra for Windows

Myra is a Windows desktop work companion from **Utterance LLC**. Give her a repetitive task involving files, websites, spreadsheets, or documents, and she can help carry it through while keeping you in the loop.

## Download

Download **Myra Private Setup 0.1.1.exe** from this repository’s Releases page and run it on a 64-bit Windows PC.

During setup, you can choose where to install Myra and whether to add a desktop shortcut. Open Myra from the Start menu or desktop shortcut after installation.

## What Myra can help with

- Find, organize, rename, move, and recover files.
- Gather and summarize information from websites in Myra’s browser.
- Help read and update Excel workbooks and Word documents.
- Create and make straightforward edits to PowerPoint presentations.
- Take requests by text or intentional hold-to-talk voice.
- Ask for your input when a task needs a decision and report what she could verify.

Some tasks depend on the relevant app being installed, your browser being available, and the required permissions. Myra does not control every app or website, and some actions may require your confirmation.

## Private beta and included service configuration

This is a **private beta build**. The installer includes the service configuration used when it was packaged, which may include API credentials for the intended recipient. Share this installer only with that recipient. Do not publish it in a public repository or share it with anyone who is not authorized to use those credentials. If it is exposed accidentally, revoke or rotate the affected keys.

The installer does not include source code or a promise of support for every Windows setup, website, or Office task. Myra’s behavior depends on the configured services and their availability.
